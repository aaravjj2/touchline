# Historical regression reports

`three-club-careers/` retains generated regression worlds, compatibility records and audit findings from earlier development. They are evidence for the build and scenario named in each report, not personal player saves or proof that all later releases reran the same checks.

For the current analytical feature, start with [analytics verification](../docs/ANALYTICS-VERIFICATION.md). For earlier public game releases and renderer limitations, use [verification history](../docs/VERIFICATION.md). Some historical reports refer to private-era release notes that were not included in the public source snapshot; their original dates and claims are retained rather than reconstructed.
