# Public browser deployment

Play at **https://touchline-beta-ten.vercel.app/**. Build **3.17.0-preview.3** was deployed to production on 26 October 2026 from commit `46d5ccf992b2fc6f974bb38d540ae85c42c6d15f`.

The existing Vercel `touchline` project is connected to `aaravjj2/touchline`, with production branch `main`. Settings use Framework **Other**, Root Directory **dist**, Output Directory **.**, empty build/install overrides, and no files outside the root. The already-built static browser app is served directly; the optional repository-root API adapter is outside this deployment. No live AI service is enabled.

Vercel reported **Ready**, production environment, with a six-second build. An anonymous HTTP check matched ten key deployed files byte-for-byte against the tested public source, including the offline manifest, runtime version, simulation/presentation modules and original stadium SVG.

An actual Chrome check completed passing practice, created a disposable Arsenal league-and-cup QA career, rendered its physical match, saved/left and reloaded that pending fixture, resumed it and explicitly simulated to full-time. The 1–0 result committed, a save archive downloaded, and another reload retained three points and the next opponent, Paris Saint-Germain. No browser warnings/errors were reported by the captured console check. These deployment smoke checks supplement the existing local 271-unit/99-journey suite; they do not represent another complete cloud regression run or physical-device certification.

Use a separate browser profile or `?qa=1` for disposable checks. Localhost and the public HTTPS site have different browser storage; saves do not automatically move between them. Settings & saves provides manual archive export/import with recovery copies.
