# Touchline demonstration

The existing walkthrough records public `3.17.0-preview.3`: original rendered opening and launcher, a seeded Harbour Athletic career, position cover, three match choices, actual keyboard play, a pending-match reload, explicit fast simulation to full-time, result recap, save export, repeatable practice and position-aware drafting. The current `3.18.0-preview.1` browser build has newer human figures and original 3D cards; the older video does not depict these visual updates.

[Play directly in the browser](https://touchline-beta-ten.vercel.app/). See [deployment verification](DEPLOYMENT.md) for the exact deployed commit and smoke-check scope.

[Watch/download the narrated MP4](https://github.com/aaravjj2/touchline/releases/download/v3.17.0-preview.3/touchline-demo.mp4), [download captions](https://github.com/aaravjj2/touchline/releases/download/v3.17.0-preview.3/touchline-demo.srt), or [get the playable ZIP](https://github.com/aaravjj2/touchline/releases/download/v3.18.0-preview.1/touchline-3.18-preview.zip). The ZIP requires Node.js 24 or later, no package installation: extract, run `node server.mjs`, and open http://127.0.0.1:4280/?qa=1.

The recording is actual application footage driven by browser automation. The original-club career is deliberately prepared, not a naturally played personal season. Captions identify fast simulation and the sandbox's unverified real-world data. Generic Windows synthetic narration is disclosed; no external music or voice cloning is used.

This is a product demonstration, not a benchmark, human test or proof of physical-phone compatibility. Native dialog and game UI remain functional in the captured app; captions are added only in the isolated recording DOM. No simulation state is altered to manufacture a successful action or a win.

To try the app, follow the root README. For LaunchPad, this project remains a draft until an actual final submission is confirmed. A public repository or release does not automatically enter the event.
