# Touchline demonstration

Current build: **3.18.0-preview.2**. The current walkthrough shows the original animated opening, a deliberately prepared Harbour Athletic career, natural-position cover, three match choices, actual keyboard input, pending-match reload, explicit fast simulation to full-time, result recap, save export, repeatable practice and real Draft & Europe photos.

[Play in your browser](https://touchline-beta-ten.vercel.app/) · [Watch/download the current MP4](https://github.com/aaravjj2/touchline/releases/download/v3.18.0-preview.2/touchline-demo.mp4) · [Captions](https://github.com/aaravjj2/touchline/releases/download/v3.18.0-preview.2/touchline-demo.srt) · [Transcript](DEMO-TRANSCRIPT.md) · [Playable ZIP](https://github.com/aaravjj2/touchline/releases/download/v3.18.0-preview.2/touchline-3.18.2-preview.zip).

The ZIP requires Node.js 24 or later: extract the whole folder, run node server.mjs inside it, and open http://127.0.0.1:4280/?qa=1. No dependency install or external service is required. Export saves before changing devices or origins. The extracted ZIP passed its 5,400-file integrity audit plus browser training and Draft-photo smoke checks.

The recording is actual application footage driven by browser automation. The original-club career is prepared QA data, separate from personal saves. Capture-only captions and generic Microsoft Zira synthetic narration are disclosed; no external music or voice cloning. Fast simulation is labelled. The game has no live AI and does not claim verified current registrations, contracts or valuations. Photos may show another year or kit; [individual credits](https://touchline-beta-ten.vercel.app/assets/portraits/credits.html) are retained.

This is a product demonstration, not a benchmark, human test or physical-phone certification. The 3.17 video remains an older historical release artifact. Current test scope is in [VERIFICATION.md](VERIFICATION.md), and [LAUNCHPAD-CONTRIBUTIONS.md](LAUNCHPAD-CONTRIBUTIONS.md) distinguishes event work from the prior project. Publishing source or media is not a Devpost entry.
