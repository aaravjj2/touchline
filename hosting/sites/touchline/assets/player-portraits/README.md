# Original 3D player portraits

Rendered from the original Touchline human anatomy mesh, on the credited Kenney CC0 skeleton. These are fictional visual identities, not photographs, scans or accurate likenesses of named people. Neutral studio kits avoid stale club colours after transfers. Known identities use explicit person/profile/card aliases; created players use deterministic original variants. No live WebGL renderer is needed to display cards.

Rebuild with `node scripts/build-player-portraits.mjs`; coverage.json records every generated file.
